How I build

Server-authoritative, data-safe, easy to tune.

Game state lives on the server, clients only send intent, and every tunable number sits in one config module so balancing a wave or a rebirth cost is a one-line change.

WaveService.server.luauLuau
-- Scale each wave from the difficulty tier config
local Config = require(ReplicatedStorage.Config.Waves)

local function buildWave(tier: string, wave: number)
  local t = Config.Tiers[tier]
  local count = math.floor(t.baseCount * t.growth ^ wave)
  local isBoss = wave % t.bossEvery == 0

  return {
    enemies = isBoss and { "Boss" } or pickEnemies(t, count),
    healthMult = t.hpScale * wave,
    reward = t.reward * wave,
  }
end
